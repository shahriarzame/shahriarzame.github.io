A Simple Example: A Small Parcel-Sorting Operation

A sorting station pays €4 per shift for equipment (fixed cost) and €1 per parcel for basic handling. It can process up to 4 parcels efficiently; beyond that, congestion and overtime add increasing variable costs.

FC = 4
VC(q) = q + 0.5[max(0, q − 4)]2
AFC = FC / q  ·  AVC = VC / q
ATC = AFC + AVC = (FC + VC) / q
